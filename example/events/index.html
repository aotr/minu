Events + cancellation

Every request emits a small lifecycle. Events bubble, so one document listener can log them. minu:beforeRequest is cancelable.

The response from /demo/time appears here.

Event log ready.

Lifecycle

EventWhenDetail
minu:contentSetupElement initialized{ url, trigger }
minu:beforeRequestBefore fetch; cancelable{ url, method, element }
minu:contentLoadedHTML parsed and swapped{ html, url, method }
minu:contentErrorNetwork, HTTP, timeout{ error, url }
minu:afterRequestAlways, after cleanup{ url, method, ok }

How it works

  1. The document listener receives all events because Minu dispatches them with bubbles: true.
  2. Tick “Cancel the next request”, then click “Run request”: the beforeRequest listener calls event.preventDefault().
  3. A cancelled request never calls fetch and fires no afterRequest.
  4. The timeout button aborts after 500 ms; the demo endpoint answers after 1.5 s.
  5. Timeout and failure both fire contentError, then afterRequest with ok: false.
document.addEventListener('minu:beforeRequest', (event) => {
    if (shouldCancel) event.preventDefault();
});

document.addEventListener('minu:contentLoaded', (event) => {
    console.log('loaded', event.detail.url);
});

document.addEventListener('minu:contentError', (event) => {
    console.warn('failed', event.detail.error);
});
