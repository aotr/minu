Minu Examples

One runnable page per scenario. Every page explains the attribute, the request flow, and the server response. Start the demo server instead of a static file server — several examples use dynamic endpoints. 

npm run examples
# open http://localhost:3000

Common setup

  1. Load dist/minu.min.js and call minu.init().
  2. Add a verb attribute and a trigger: <button minu-get="/url" minu-trigger="click">
  3. Pick a target with minu-target, or let Minu use an inner minu-content.
  4. The server returns HTML; Minu sanitizes it and applies the swap mode.

Full attribute and event reference: readme.md. The demo server is example/server.js, with no runtime dependencies.
