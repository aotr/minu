Tools by the author of Minu

Three small tools for the messy parts.

Minu is about sending less JavaScript. These three tools are about preparing the assets and keeping the browser and editor out of your way. All are MIT licensed and install from npm.

Images

PixelPress

Bulk image compression and transcoding. Point it at a file, folder, or glob and get AVIF, WebP, JPEG, or PNG at responsive widths, with a cache, manifest, HTML report, and ready-to-paste <picture> snippets.

npm install --save-dev pixelpress
npx pixelpress "public/images/**/*.{jpg,png}" -o dist -f avif,webp
Source npm

Editor

hue-shift

Give every VS Code project its own window colour and every JetBrains project a matching toolbar. A terminal-first Peacock alternative that walks a projects folder in one pass. No extension, no daemon, no config file to hand-edit.

npx hue-shift-cli --random
# or install it globally:
npm install -g hue-shift-cli
Website Source npm

Accessibility

open-a11y

A framework-agnostic accessibility toolbar with 30 tools and 7 profiles. It ships as web components with adapters for Vanilla JS, React, Vue, Svelte, Angular, Laravel, Blade, and Livewire. Preferences persist locally, and the widget is self-hosted.

npm install @aotr/open-a11y
// or load the browser bundle:
// dist/open-a11y.js
Website Source npm

These are separate tools, not Minu plugins. They come from the same small-tool habit: solve one job, keep the install simple, and document the edges.
